# Автоимперия

Учебный сайт автосервиса на PHP и SQLite. Клиент выбирает автомобиль, услуги и время визита, добавляет пожелания и получает талон. В кабинете мастера есть календарь постов и журнал заказов с поиском, сортировкой и страницами по 10 заказов.

## Показ в браузере

- [Открыть сайт в GitHub Codespaces](https://codespaces.new/Hurricaneddy/autoimperia). Войдите в GitHub, выберите ветку `main` и нажмите **Create codespace**. После запуска сайт откроется в новой вкладке. Если вкладка не появилась, внизу редактора откройте **Ports** и нажмите на ссылку порта **8000**.
- [Открыть предыдущую онлайн-демоверсию](https://autoimperia-coursework.vercel.app/). На ней доступны главная, онлайн-запись и кабинет мастера. Для показа личного кабинета клиента используйте Codespaces или локальный запуск.

Для демонстрации записи и кабинета мастера используйте один браузер. Логин мастера `demo`. Для локальной SQLite пароль `autoimperia-demo`. Для Supabase задайте пароль в Codespaces.

## Запуск на компьютере

1. Скачайте репозиторий или распакуйте архив.
2. Установите PHP 8.2 или новее с расширениями PDO SQLite и mbstring.
3. В терминале откройте папку проекта и выполните:

   ```sh
   php -S 127.0.0.1:8000 -t public api/router.php
   ```

4. Откройте [сайт](http://127.0.0.1:8000/), [вход для клиента](http://127.0.0.1:8000/client/login.php) или [кабинет мастера](http://127.0.0.1:8000/admin/login.php).

Логин мастера `demo`, пароль `autoimperia-demo`. В журнале мастера можно искать заявки по коду, автомобилю, госномеру, имени, телефону и пожеланиям. Для просмотра заявок во временной версии Vercel используйте тот же браузер, что и при записи.

## Личный кабинет клиента

1. На клиентском сайте нажмите «Вход для клиента», затем «Зарегистрироваться». В учебном проекте используйте вымышленные имя, телефон и почту. Вход работает по почте и паролю.
2. Добавьте автомобиль в гараж и откройте запись из его карточки. Заявка появится в разделе «Предстоящие». Введите пробег при записи, если хотите, чтобы следующее обслуживание рассчитывалось и по километражу.
3. Когда мастер завершит заказ, он появится в «Истории ремонтов». На странице видны даты, услуги, статус, стоимость и пожелания. «Периодичность выполненных работ» показывает число повторений и промежуток между двумя последними визитами с этой услугой, если они есть.
4. В рекомендациях укажите текущий пробег. Кабинет сравнит его и текущую дату со сроком после последней завершённой работы. Интервалы служат примером для защиты. Для своего автомобиля ориентируйтесь на регламент производителя.

Гостевые онлайн-записи можно перенести в новый аккаунт при регистрации в том же сеансе с тем же телефоном. Заказы из другого сеанса и заявки, внесённые мастером вручную, автоматически к аккаунту не привязываются.

## Постоянная база Supabase в Codespaces

Миграция в `supabase/migrations` создаёт закрытую схему `autoimperia` и переносит учебные справочники. В проекте Supabase `autoimperia` миграция уже применена.

1. В Supabase откройте **Connect → Session pooler**. Возьмите URI и подставьте пароль базы. Для пароля с особыми символами используйте URL-кодирование.
2. В [настройках секретов GitHub Codespaces](https://github.com/settings/codespaces) добавьте два секрета с доступом только к `Hurricaneddy/autoimperia`.
   - `AUTOIMPERIA_DATABASE_URL` — заполненный URI из Supabase, который начинается с `postgresql://`.
   - `AUTOIMPERIA_MASTER_PASSWORD` — придуманный пароль сотрудника длиной не менее 16 символов, с логином `demo`.
3. Создайте Codespace или остановите и пересоберите существующий через **Codespaces: Rebuild Container**, затем откройте порт **8000**. Оставьте доступ к порту приватным. Учётные записи и записи о ремонте хранятся в Supabase между перезапусками.

Секреты задаются в настройках Codespaces. Если URI не задан, сайт в Codespaces запускается с локальной SQLite. Если URI задан, ошибки соединения с Supabase приводят к ошибке запуска страницы, что позволяет заметить неправильный пароль или адрес.

## Публикация на Vercel

В корне проекта уже есть `vercel.json` с маршрутизацией и версией PHP-адаптера. Из распакованной папки запустите `npx vercel --prod` и выберите нужный проект. Чтобы обновить прежнюю публичную ссылку, выберите существующий проект `autoimperia-coursework` в своём аккаунте.

## Данные демоверсии

В архиве есть чистая SQLite с учебным каталогом и демоучётной записью мастера. Реальные платежи не проводятся.

При локальном запуске создаётся постоянный файл `var/autoimperia.sqlite`. Аккаунты и история сохраняются при перезапуске сервера и доступны после повторного входа, в том числе из другого браузера. Файл `var/` исключён из выгрузки на Vercel.

На Vercel используется временная база на сеанс. При смене браузера или перезапуске экземпляра записи и аккаунты могут оказаться недоступны. Для постоянного клиентского кабинета онлайн понадобится постоянная база.
