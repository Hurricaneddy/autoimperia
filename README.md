# Автоимперия

Учебный сайт автосервиса на PHP и SQLite. Клиент выбирает автомобиль, услуги и время визита, добавляет пожелания и получает талон. В кабинете мастера есть календарь постов и журнал заказов с поиском, сортировкой и страницами по 10 заказов.

## Запуск на компьютере

1. Распакуйте архив.
2. Установите PHP 8.2 или новее с расширениями PDO SQLite и mbstring.
3. В терминале откройте распакованную папку и выполните:

   ```sh
   php -S 127.0.0.1:8000 -t public api/router.php
   ```

4. Откройте [сайт](http://127.0.0.1:8000/) или [кабинет мастера](http://127.0.0.1:8000/admin/login.php).

Логин мастера `demo`, пароль `autoimperia-demo`. Создайте заявку и откройте кабинет в том же браузере. В журнале выберите «Все даты» или «История (завершённые и отменённые)». Поиск учитывает код талона, автомобиль, госномер, имя, телефон и пожелания клиента.

## Публикация на Vercel

В корне проекта уже есть `vercel.json` с маршрутизацией и версией PHP-адаптера. Из распакованной папки запустите `npx vercel --prod` и выберите нужный проект. Чтобы обновить прежнюю публичную ссылку, выберите существующий проект `autoimperia-coursework` в своём аккаунте.

## Данные демоверсии

В архиве есть SQLite с учебным каталогом и демоучётной записью. Реальные платежи не проводятся. Для каждого сеанса создаётся временная база. При смене браузера или перезапуске экземпляра на Vercel заявки могут оказаться недоступны.
